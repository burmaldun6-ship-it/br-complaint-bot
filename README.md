# Black Russia Complaint Bot

**Скриншот → проверка → черновик жалобы.**

Telegram-бот, который помогает подготовить текст жалобы по скриншоту из
**Black Russia**. Пользователь указывает свой ник, ссылку на доказательство
и конкретного игрока — бот передаёт изображение vision-модели и возвращает ответ.

**Python 3.11+ · aiogram 3 · SQLite · OpenAI-compatible API · MIT**

> Неофициальный инструмент. Бот не отправляет жалобы на форум автоматически
> и не гарантирует правильность выводов ИИ. Перед публикацией проверьте текст,
> доказательства и актуальные правила сервера.

## Как это выглядит

Отправьте боту **фото**, а в подписи укажите три строки:

```text
Ваш ник:Cat_Boy
Ссылка на фото:https://ibb.co/abc123
На какого игрока писать жалобу(ник):Cat_Male
```

- Фото нужно прикрепить именно как изображение, не как документ.
- На скриншоте должны быть видны нужные доказательства, включая `/time`
  согласно правилам, описанным в промпте.
- Ники — две части латиницей через `_`, каждая начинается с заглавной буквы.
  Проверка в коде: `^[A-Z][a-zA-Z]*_[A-Z][a-zA-Z]*$`.
- Ссылка допускается в формате `http://` или `https://`. Само изображение
  бот получает из Telegram; по ссылке он его не скачивает.

Правила анализа находятся в [prompt.md](prompt.md). Это инструкции для модели,
а не гарантия достоверности её ответа.

## Возможности

- Анализ фотографии и подготовка ответа через vision-модель.
- Проверка формата подписи и обоих ников до запроса к ИИ.
- Суточные лимиты с хранением в SQLite; сутки считаются по **Europe/Moscow**.
- Резервирование слота на время запроса, чтобы параллельные обращения
  не обходили установленный лимит в рамках одного процесса бота.
- Админ-панель: состояние, общий лимит, лимит пользователя, выгрузка журнала.
- Журнал обработанных обращений к ИИ и ошибок в Markdown.

**По умолчанию — 5 обработанных запросов в сутки.** В счётчик попадает
успешно полученный непустой ответ модели, в том числе ответ с отказом составить
жалобу. Это не обязательно пять готовых жалоб. Технические ошибки по логике
обработчика освобождают зарезервированную попытку.

Администратор из `ADMIN_ID` не ограничен квотой. Индивидуальный лимит имеет
приоритет над общим; лимит `0` запрещает новые запросы обычному пользователю.

## Быстрый запуск

Нужны токен Telegram-бота от **@BotFather**, Telegram ID администратора
и ключ API сервиса с поддержкой изображений.

### Linux / macOS

```sh
git clone https://github.com/burmaldun6-ship-it/br-complaint-bot.git br-complaint-bot
cd br-complaint-bot
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`, затем загрузите переменные и запустите бота:

```sh
set -a
. ./.env
set +a
python bot.py
```

> **Важно:** приложение само не читает `.env` — в коде используется `os.getenv`.
> Простого копирования файла недостаточно. Команда выше загружает ваш `.env`
> как shell-файл: используйте только свой доверенный файл с корректным синтаксисом.
> При каждом новом терминале активируйте окружение и загрузите переменные заново.

### Windows / PowerShell

```powershell
git clone https://github.com/burmaldun6-ship-it/br-complaint-bot.git br-complaint-bot
cd br-complaint-bot
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install tzdata

$env:BOT_TOKEN = "ТОКЕН_ОТ_BOTFATHER"
$env:ADMIN_ID = "ВАШ_TELEGRAM_ID"
$env:OPENAI_API_KEY = "КЛЮЧ_API"
python bot.py
```

`tzdata` нужен, если в системе нет базы часовых поясов для `Europe/Moscow`;
в Windows её часто нет. Если PowerShell блокирует активацию venv, можно
вызывать `.\.venv\Scripts\python.exe` напрямую вместо `python`.

## Настройки

Шаблон всех переменных: [.env.example](.env.example).

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота | Обязательно |
| `ADMIN_ID` | Числовой Telegram ID администратора | Обязательно |
| `OPENAI_API_KEY` | Ключ выбранного AI-сервиса | Обязательно |
| `OPENAI_BASE_URL` | OpenAI-compatible endpoint | `https://api.openai.com/v1` |
| `OPENAI_MODEL` | Модель, поддерживающая изображения | `gpt-4.1-mini` |
| `DATABASE_PATH` | Путь к SQLite | `data/bot.sqlite3` |
| `DEFAULT_DAILY_LIMIT` | Начальный общий лимит | `5` |

Используется **Chat Completions**: системный промпт, текст и изображение
в формате data URL. Endpoint и модель должны поддерживать этот формат
и передаваемый параметр `temperature=0`. Совместимость конкретного стороннего
провайдера нужно проверить отдельно. Запросы могут тарифицироваться сервисом.

`DEFAULT_DAILY_LIMIT` — начальное значение. Если общий лимит уже изменён
через админ-панель и сохранён в SQLite, используется значение из базы.

## Команды и администрирование

| Команда | Действие |
| --- | --- |
| `/start` | Инструкция и пример подписи |
| `/admin_panel` | Админ-панель, только для пользователя из `ADMIN_ID` |

В панели можно посмотреть состояние бота и последнюю сохранённую ошибку API,
изменить общий лимит и установить лимит конкретному пользователю.
Статус отражает журнал, а не выполняет отдельную live-проверку AI-провайдера.

Для индивидуального лимита отправьте:

```text
123456789 10
```

Для общего — одно целое неотрицательное число. Кнопка экспорта отправляет
`ai_logs.md` с сохранёнными обращениями и ошибками.

## Данные и конфиденциальность

- Фото и текст запроса передаются выбранному AI-провайдеру. Обращения к Telegram
  и AI API необходимы для работы: бот не является офлайн-инструментом.
- SQLite хранит Telegram ID и имя, игровой ник, ссылку на доказательство,
  описание запроса, ответ модели или текст ошибки, а также счётчики лимитов.
- Фото как отдельный файл в SQLite этот код не сохраняет. Политика хранения
  данных самим AI-провайдером определяется выбранным сервисом.
- Экспорт журнала содержит пользовательские данные. Не публикуйте его,
  `.env`, базу данных и ключи API в репозитории или общих чатах.
- Автоматическое удаление старых записей журнала в коде не предусмотрено.

## Развёртывание

Бот работает через **long polling**. Отдельный веб-сервер не требуется.
При старте старые Telegram updates сбрасываются через `drop_pending_updates=True`.

На Python-хостинге, в том числе WispByte:

1. Установите зависимости из `requirements.txt`.
2. Задайте переменные окружения в панели хостинга.
3. Укажите команду запуска `python bot.py`.
4. Для `DATABASE_PATH` выберите постоянный диск или volume.

При потере SQLite пропадут лимиты, счётчики и журнал. Многопроцессный запуск
и несколько реплик этого бота отдельно не проработаны — начинайте с одного
процесса и не используйте один токен одновременно в нескольких polling-процессах.

## Структура

| Файл | За что отвечает |
| --- | --- |
| `bot.py` | Запуск, Telegram polling, подключение базы |
| `handlers.py` | Сообщения, валидация, квоты, админ-панель |
| `ai.py` | Запрос к vision-модели |
| `config.py` | Чтение переменных окружения |
| `db.py` | SQLite, лимиты, журнал |
| `prompt.md` | Инструкции анализа скриншота |
